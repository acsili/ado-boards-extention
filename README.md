# Аватарки исполнителей в чеклисте доски TFS

После установки на доске TFS у каждой задачи в списке под карточкой появится круглая аватарка того, кто её делает.

Также в свернутом состоянии чеклиста аватарки исполнителей отображаются на самой карточке (рядом со счетчиками задач и багов).

Установить можно одним из двух способов, **выберите один**. Если поставить оба, аватарки будут дублироваться.

Файлы в этой папке:
- `ado-checklist-avatars.user.js` нужен для способа А;
- папка `ado-checklist-avatars` нужна для способа Б.

Оба варианта поддерживаются на большинстве браузеров.
Ниже на примере Chrome

---

## Способ А. Через менеджер пользовательских скриптов 

Например **Tampermonkey**

1. Установите расширение **Tampermonkey** из Chrome Web Store: найдите «Tampermonkey» и нажмите «Установить».
2. Откройте в адресной строке `chrome://extensions`.
   - Найдите Tampermonkey, нажмите **«Подробнее»** и включите переключатель **«Allow User Scripts»** («Разрешить пользовательские скрипты»).
   - Если такого переключателя нет, включите **«Режим разработчика»** в правом верхнем углу страницы.
3. Нажмите на иконку Tampermonkey на панели браузера и выберите **«Create a new script»** («Создать новый скрипт»).
4. Удалите весь текст, который там уже есть.
5. Откройте файл `ado-checklist-avatars.user.js` в Блокноте, скопируйте всё и вставьте в окно Tampermonkey.
6. Нажмите **Ctrl+S**, чтобы сохранить, и закройте вкладку редактора.
7. Откройте доску TFS и обновите страницу.

## Способ Б. Через расширение

1. Скопируйте папку `ado-checklist-avatars` к себе на компьютер, например в `C:\Tools\`.
   Папку потом нельзя удалять и переносить: Chrome берёт расширение из неё. Сетевой диск для этого не подходит.
2. Откройте в адресной строке `chrome://extensions`.
3. Включите **«Режим разработчика»** в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** и выберите скопированную папку `ado-checklist-avatars`.
5. Откройте доску TFS и обновите страницу.

При запуске Chrome может предлагать отключить расширения в режиме разработчика. Нажмите «Отмена» или закройте это окно.

---

## Как обновить

- **Способ А:** откройте Tampermonkey → «Dashboard» → нажмите на скрипт, замените текст новым из файла `ado-checklist-avatars.user.js`, сохраните, обновите страницу с доской.
- **Способ Б:** замените файлы в своей папке новыми из `ado-checklist-avatars`, в `chrome://extensions` нажмите на расширении кнопку ⟳, затем обновите страницу с доской.
